# Clean up your README

> **Story · a fictional companion.** The instructions were for getting here. You are here. What stays in GitHub is yours.

The setup instructions have done their work. Take them out, and the README becomes your own.

1. Open `README.md` at the top level of your repository.
2. Select the pencil icon above the file. Its tooltip reads **Edit this file**, and the file opens in an editor.
3. Find the marker line that begins `<!-- START-HERE:begin`. It sits directly under the title.
4. Find the marker line `<!-- START-HERE:end -->` further down the file.
5. Select everything from the start of the begin marker line to the end of the end marker line.
6. Delete the selection. Both marker lines go with it.
7. Check that the first line of the file is still the title that begins `# DESN 368`.
8. Check that the heading `## Three places` is still there, just below the title.
9. Select the **Preview** tab above the editor. The editor shows the file as a reader sees it.
10. Read the preview. The setup steps are gone, and your own sections are all there.
11. Select the green **Commit changes...** button at the top right. A dialog opens.
12. Type a message in the first box of the dialog, such as "Clean up the README".
13. Select the green **Commit changes** button in the dialog. GitHub saves your shorter README and shows it on the front page of your repository.

Nine sections stay in your README:

- Three places
- About me
- My toolkit
- Course progress
- Projects
- Look-backs
- Learning Passport
- Course links
- Help

You clean up again at each of the five project handoffs, beside the look-back you write there. Go back to [ONBOARDING-CHECKLIST.md](ONBOARDING-CHECKLIST.md) now and tick box 6, with the steps under **How to tick a box**. Every box is then ticked, and you may delete the `setup/` folder.
