### How to tick a box

1. Select the pencil icon above this file. Its tooltip reads **Edit this file**, and the file opens in an editor.
2. Find the box you want to tick in the list above.
3. Change that line's `[ ]` to `[x]`. The `x` goes between the brackets with no space around it.
4. Select the green **Commit changes...** button at the top right. A dialog opens.
5. Type a short message in the first box of the dialog, such as "Tick box 1".
6. Select the green **Commit changes** button in the dialog. The box shows as ticked in the list.

## 1. GitHub account and profile

Take one of the two paths below, then complete **Your profile**.

### If you have no GitHub account

1. Open `https://github.com/join` in a browser. GitHub's sign-up form opens.
2. Type your `@ewu.edu` address in the **Email** box.
3. Type a password in the **Password** box.
4. Type a username you would show an employer in the **Username** box. Your username appears in the addresses of your GitHub profile and your repositories.
5. Open the **Your Country/Region** menu. The list of countries drops down.
6. Choose your country in that list.
7. Select **Create account**.
8. Solve the verification puzzle if GitHub shows one.
9. Open the email GitHub sends to your `@ewu.edu` address. A verification code is in the message.
10. Enter the code in the form. GitHub opens your new account.
11. Go on to **Your profile** below.

### If you already have a GitHub account

Use the account you have. Do not make a second account for this course.

1. Open `https://github.com` in a browser.
2. Sign in to your account. Your avatar shows at the top right.
3. Select your profile picture at the upper right. A menu opens.
4. Select **Settings** in that menu. Your account settings open.
5. Select **Emails** in the sidebar, under "Access". The Emails page lists every address on your account.
6. Look for your `@ewu.edu` address in that list. One of the three cases below matches what you see.

**Case A.** Your `@ewu.edu` address is in the list, and nothing under it offers to resend a verification email. GitHub has verified the address, so nothing here is left to do.

1. Go on to **Your profile** below.

**Case B.** Your `@ewu.edu` address is in the list, and a link under it offers to resend a verification email. GitHub has not verified the address yet.

1. Select **Resend verification email** under that address. GitHub emails a verification link to your `@ewu.edu` address.
2. Open that email.
3. Select the link in the message. GitHub marks the address as verified.
4. Go on to **Your profile** below.

**Case C.** Your `@ewu.edu` address is not in the list.

1. Type your `@ewu.edu` address in the box under "Add email address".
2. Select **Add**. The address joins the list, and GitHub emails a verification link to it.
3. Open that email.
4. Select the link in the message. GitHub marks the address as verified.
5. Go on to **Your profile** below.

### Your profile

1. Open your profile page.
2. Select **Edit profile**. The name and bio boxes open on the page.
3. Type your full name in the **Name** box.
4. Write a one-line bio in the **Bio** box.
5. Add a profile photo if you want one. A photo is optional.
6. Select **Save**. Your name and your bio show under your username on your profile page.

## 2. GitHub Student Developer Pack

1. Open `https://github.com/settings/education/benefits` in a browser. The Education benefits settings page opens.
2. Select **Start an application**. The application form opens.
3. Choose your verified `@ewu.edu` address as your school email address.
4. Add the proof of enrollment the form asks for.
5. Select **Submit application**. GitHub shows your application as pending.

Approval can take several days. Nothing in this course waits on it.

Account approval is not permission to use AI. GitHub Copilot stays off until Week 3. From Week 3 you ask it to explain. You do not ask it to fix your code.

## 3. Figma

Your Figma account must use your school-issued `@ewu.edu` address. Change the address in your Figma account settings first if you made the account with a personal address.

1. Open `https://www.figma.com/education/apply` in a browser. The education application opens.
2. Select **Higher Ed**. The higher-education form opens.
3. Agree to the terms.
4. Select **Submit**. Figma hands you on to a SheerID form.
5. Fill in the SheerID form.
6. Submit the SheerID form. SheerID emails you within a few days to confirm.

Figma's AI features stay off until the class reaches them.

## 4. CodePen

1. Open `https://codepen.io/accounts/signup/user/free` in a browser. The free sign-up form opens.
2. Type your name in the **Your Name** box.
3. Type a username you would show an employer in the **Choose a username** box. Your username appears in the addresses of your pens.
4. Type your email address in the **Email** box.
5. Type a password in the **Choose Password** box.
6. Select **Submit**. CodePen creates your free account.

## 5. Update your toolkit

1. Open `README.md` at the top level of your repository.
2. Select the pencil icon above the file. Its tooltip reads **Edit this file**, and the file opens in an editor.
3. Scroll down to the "My toolkit" list.
4. Fill in the first four lines with your own addresses and usernames.
5. Write Pending or Approved on the Student Developer Pack line. Pending is the right word until GitHub approves your application.
6. Select the green **Commit changes...** button at the top right. A dialog opens.
7. Type a short message in the first box of the dialog, such as "Fill in my toolkit".
8. Select the green **Commit changes** button in the dialog. Your five filled-in lines show in the file.
