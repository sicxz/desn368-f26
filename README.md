## Start here

This repository is your own private copy of the course workspace. You got it by accepting the **Workspace** assignment. You work in it all quarter. The first step checks that the copy is yours. Steps 2 through 6 set up the copy. The last step deletes these instructions.

Read the address bar first. The instructor's copy has this address: `github.com/code-and-design-teaching/desn368-f26-workspace-template`. Do not use the **Fork** button or the **Use this template** button there. Open the **Workspace** assignment link in Canvas to get your own copy. The Week 0 lessons on the course site walk you through accepting the **Workspace** assignment.

### Step 1: Check that this copy is yours

1. Read the address bar. The address begins `github.com/code-and-design-teaching/`. Your GitHub username appears at the end.
2. Look beside the repository name at the top of the page. A **Private** label sits there.
3. Ask the instructor before you go on if the address is wrong or the **Private** label is missing.

Private means that only you and the instructor can open this repository.

### Step 2: Make your first edit

1. Open `README.md` in your copy. That is this file.
2. Select the pencil icon above the file. Its tooltip reads **Edit this file**, and the file opens in an editor.
3. Scroll down to the "My toolkit" list. Its five lines start with bold labels.
4. Replace `[Add your profile URL]` with the address of your GitHub profile.
5. Select the green **Commit changes...** button at the top right. A dialog opens.
6. Type a short message in the first box of the dialog, such as "Add my profile URL".
7. Select the green **Commit changes** button in the dialog. The dialog closes, and your new line shows in the file.

A commit is a saved, named change to the files in your repository.

### Step 3: Work through the setup checklist

1. Open [setup/ONBOARDING-CHECKLIST.md](setup/ONBOARDING-CHECKLIST.md) in your copy. The six boxes sit at the top.
2. Tick box 1. You did section 1 before you accepted the **Workspace** assignment. **How to tick a box** at the top of the checklist shows you how.
3. Work through sections 2, 3, 4 and 5 in order. They cover the Student Developer Pack, Figma, CodePen and your toolkit.
4. Tick each of boxes 2, 3, 4 and 5 as you finish its section.
5. Leave section 6 for later. Step 7 sends you to `setup/CLEANUP.md`. That file sends you back here to tick box 6.
6. Come back to this page once boxes 1 to 5 are ticked.

### Step 4: Mark where you are starting

This file is not graded, and you answer it again at the end of the quarter.

1. Open [week-0/where-i-am-starting.md](week-0/where-i-am-starting.md) in your copy.
2. Select the pencil icon above the file. Its tooltip reads **Edit this file**, and the file opens in an editor.
3. Tick one box under each heading by changing that line's `[ ]` to `[x]`. The `x` goes between the brackets with no space around it.
4. Write one line under "One thing I hope to make by the end of the quarter".
5. Select the green **Commit changes...** button. A dialog opens.
6. Type a short message, such as "Mark where I am starting".
7. Select the green **Commit changes** button in the dialog. Your ticks show in the file.

### Step 5: Write your introduction

1. Open the Week 0 lessons on the course site. The site teaches you Markdown there, before you write any.
2. Open [week-0/introduction.md](week-0/introduction.md) in your copy.
3. Select the pencil icon above the file. Its tooltip reads **Edit this file**, and the file opens in an editor.
4. Write a few sentences under each of the four headings.
5. Select the green **Commit changes...** button. A dialog opens.
6. Type a short message, such as "Write my introduction".
7. Select the green **Commit changes** button in the dialog. Your four answers show in the file.

### Step 6: Submit

Submit the link to your repository in Canvas.

### Step 7: Clean up

1. Open [setup/CLEANUP.md](setup/CLEANUP.md) in your copy.
2. Work through its numbered steps. They take these setup instructions out of your README.
3. Go back to the checklist when `CLEANUP.md` sends you there at its end.
4. Tick box 6. Every box is now ticked, and you may delete the `setup/` folder.
